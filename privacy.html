Privacy Policy for sevenstreams-247 and bleepblorp-chat

Effective date: October 5, 2026

sevenstreams-247 and bleepblorp-chat are private tools operated by the owner of the PNW Coast Off-Grid YouTube channel. Both apps use YouTube API Services. sevenstreams-247 manages that channel's own live broadcasts. bleepblorp-chat reads live chat on those broadcasts and posts replies as Bleep Blorp Bot. Only the channel owner authorizes them. Viewers do not sign in.

YouTube API Services

Both sevenstreams-247 and bleepblorp-chat use YouTube API Services. Use of YouTube data is also described by the Google Privacy Policy (http://www.google.com/policies/privacy) and the YouTube Terms of Service.

What YouTube data is accessed

sevenstreams-247, with the channel owner's authorization, accesses the owner's live broadcasts and live streams: broadcast and stream ids, titles, descriptions, privacy status, thumbnails, and broadcast status. It creates and binds broadcasts, transitions them, updates titles, descriptions, and privacy, sets thumbnails, and inserts ad-break cuepoints on the owner's own live broadcast. YouTube, not this app, serves those ads on the stream.

bleepblorp-chat, with the channel owner's authorization, accesses the live video id and active live chat id, public upload titles when a viewer asks what the channel has posted, and live chat messages on the owner's streams (author display name, channel id, message text, and membership badge). It posts replies into that live chat as Bleep Blorp Bot.

The apps use this data to run the daily live broadcast and to answer viewers in that chat. They do not use it for advertising profiles, and they do not sell it.

What is stored, and for how long

Authorization tokens for the channel owner are stored on the owner's private server for as long as that authorization stays active, and only to call YouTube API Services for the purposes on this page. Other stored YouTube API data, including broadcast details and live chat records, is kept only as long as needed to operate the apps and for no longer than 30 days. After 30 days it is deleted or refreshed from YouTube.

Live chat records stored for bleepblorp-chat are the viewer's channel id, display name, message text, and the reply that was posted. They stay on the owner's private server. They are not sold and they are not given to other viewers.

How the data is used and shared

The channel owner is the only person who operates these apps. YouTube receives the API requests the apps make, because that is how YouTube API Services work.

bleepblorp-chat sends the chat message text, and the display name needed to reply, to Anthropic so it can draft the reply. Anthropic does not receive YouTube credentials or authorization tokens. sevenstreams-247 does not send viewer data to Anthropic.

The apps do not allow other parties to serve advertisements or other content inside the apps. They do not place, access, or recognize cookies or similar technology on viewers' devices or browsers. The public pages on this site are static and do not set cookies.

Deletion

A viewer can delete the chat data stored about them by typing !forgetme in the live chat. bleepblorp-chat then deletes that viewer's stored profile, notes, prior chat records, and question history on the owner's server immediately. Deleting data stored by these apps does not delete anything stored by YouTube. To delete data on YouTube, use YouTube itself.

Anyone can also email pnwcoastoffgrid@gmail.com and ask for stored data about them to be deleted. That request is completed as soon as possible and within 7 days.

The channel owner can revoke either app's access to the Google account at any time on the Google Account permissions page: https://myaccount.google.com/permissions (the same controls are at https://security.google.com/settings/security/permissions). After access is revoked there, stored YouTube API data that was kept under that authorization is deleted within 30 days. If the owner asks for an app to be disconnected directly, that stored data is deleted within 7 days.

Google API Services

The use and transfer of information received from Google APIs by sevenstreams-247 and bleepblorp-chat adheres to the Google API Services User Data Policy, including the Limited Use requirements.
